# lp-copywriting — 効果を書かずに選ばれる文章

## 原則: 訴求力は「効果」以外で作る

整骨院は「治る」「改善する」「満足度98%」「患者さまの声」で引っぱれない（`lp-compliance`）。
それでも選ばれる院は、次の4つで選ばれている。**reasons も hero もここから作る。**

| 軸 | 読者の頭の中 | 書く材料（事実） |
|---|---|---|
| **行きやすさ** | 仕事帰りに寄れる？待たされない？ | 受付時間、駅からの距離、駐車場、予約制、待ち時間 |
| **分かりやすさ** | 何をされるの？いくらかかるの？ | 初回の流れ、所要時間、料金表、保険が使える条件 |
| **安心** | 痛くされない？勧誘されない？ | 説明の時間をとること、施術前に確認すること、個室、衛生 |
| **人** | どんな人が見てくれるの？ | 施術者の顔写真、資格の正式名称、経歴の事実、女性施術者の在籍 |

`brief.md` の `strengths` をこの4軸に振り分け、**読者の不安（reader_worries）に答える順**に並べる。

## 文の書き方

- **1文40字以内を目安**に。スマホで2行に収まる長さ
- **主語を読者にする。**「当院は〜を大切にしています」→「初めてでも、何をするか説明してから始めます」
- **数字は事実だけ。** 「徒歩4分」「20時まで」「初回およそ60分」は良い。「98%」「1万人」は書かない
- **形容詞を事実に置き換える。** 「丁寧な説明」→「施術の前に、どこを・何のために触るかをお伝えします」
- **約束しない。** 「〜します」で書けるのは院の行動（説明する、予約を受ける）だけ。読者の体の変化は約束しない
- 「！」は使わない。誠実さを損なう

## 見出しの型

### hero
- `{地域}で、{読者の状況}のときに頼れる{接骨院/整骨院}`
- `{駅名}から徒歩{n}分。{時間の事実}まで受付の{院名}`
- 悪い例: 「あなたの痛み、根本から改善します」（効果の約束）／「本物の技術を」（比較優良）

### reasons
- `{事実}だから、{読者にとっての意味}` の形
- 例: 「20時まで受付。仕事のあとでも、その日のうちに相談できます」

## CTAの型

- 主ボタン: **行動＋手段**。「LINEで予約する」「電話で空きを聞く」
- 補足: **押した後の流れ**。「友だち追加 → 希望の日時を送るだけ。返信は受付時間内に」
- 煽らない。「今すぐ」「先着」「残りわずか」は使わない（Ⅵ.4(4)）

## FAQの型

- 質問は読者の言葉で。「予約しないと行けませんか？」
- 答えは**1文目で結論**、2文目で補足。「予約なしでも受け付けています。予約の方を優先するため、お待たせすることがあります。」

## 言い換え表（よく出るNG → 書ける形）

| 書きたくなる | 問題 | 書ける形 |
|---|---|---|
| 腰痛を根本から改善 | 効果の約束・Ⅵ.4(1) | 今の状態と、ご自身でできることを説明します |
| 痛くない施術 | Ⅵ.4(1)の例示 | 力の加減は、その都度確認しながら進めます |
| 地域No.1の実績 | 比較優良・Ⅵ.4(2) | （書かない。実績は開院年など事実だけ） |
| 患者さまの声「1回で楽に」 | 体験談の強調・Ⅵ.4(3)③ | （書かない） |
| 肩こりも保険でOK | 療養費の誤った説明 | 保険が使えるのは、急なケガ（ねんざ・打撲など）の施術です |
| 放っておくと悪化します | 不安をあおる誘導・Ⅵ.4(5) | しびれや力が入らない症状があるときは、まず医療機関を受診してください |
| 確かな技術 | Ⅵ.4(1)の例示 | 柔道整復師（国家資格）が担当します |
| 骨盤のゆがみを整える | 証明できない効果 | （書かない。施術内容は flow で手順として書く） |

## 受診勧奨（必ず入れる）

`faq` か `insurance` に、**医療機関への受診を勧める一文**を入れる。宛先は自院ではなく医療機関。

> しびれ、力が入りにくい、熱がある、夜も痛みが続くといったときは、先に医療機関（整形外科など）を受診してください。

## 書いたら自分で確かめること

1. `python3 "$PLUGIN_ROOT/scripts/legal_check.py" copy.md --mode <mode>` が通る
2. 全文から「効く・治る・改善・解消・No.1・満足度・声」を目で探す（言い換えはスクリプトをすり抜ける）
3. 各セクションが `lp-structure` の合格ラインを満たす
4. `brief.md` に無い事実を書いていない
