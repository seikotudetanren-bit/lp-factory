# lp-compliance — 整骨院LPの法令チェック

**根拠は `references/ad-guidelines.md`。記憶ではなくこれを読んでから判断する。**
このスキルは法的助言ではない。最終判断は院（必要なら保健所・弁護士）が行う。

## モード判定（最初に必ず決める）

柔整師法は**書いてよいことを限定列挙**している。LPが「広告」に当たるかで書ける範囲が大きく変わる。

| 状況 | モード | 書ける範囲 |
|---|---|---|
| 検索・Googleビジネスプロフィール・紹介で人が来る（自分で探して見に来る） | `website` | 原則として広告に当たらない（指針Ⅱ.6(6)）。ただし **Ⅵ.4「掲載すべきでない事項」** と他法令がかかる |
| リスティング広告・SNS広告・チラシのQRなど、こちらから届けて連れてくる | `advertising`（既定） | 広告に当たり得る。**柔整師法24条と告示の事項だけ**しか書けない |
| 両方 | `advertising`（既定） | 厳しい側に合わせる |

- `traffic_source` が `organic` 以外で `website` を選ぶなら、**照会先・日付・回答を `compliance_basis` に記録**する
  （`check_brief.py` がこれを強制する）
- 迷ったら `advertising`。あとで緩めるのは簡単だが、出した広告は取り消せない

## website モードの判定基準

`references/ad-guidelines.md` の2章（Ⅵ.4の(1)〜(8)）を1項目ずつ当てる。LPで特に起きやすいもの:

1. **効果の言い換え**（Ⅵ.4(1)）— 「治る」を避けて「楽になっていく」「変化を感じる」「スッキリ」と書く
2. **体験談・患者さまの声**（Ⅵ.4(3)③）— LPの定番だが、整骨院では「施術者等にとって便益を与える体験談の強調」に当たる。**載せない**
3. **ビフォーアフター写真・回復のイラスト**（Ⅵ.4(3)②、指針Ⅱ.3イ）— 写真・イラスト・アイコンも判定対象
4. **比較優良**（Ⅵ.4(2)）— 「地域No.1」「口コミ1位」「◯◯に掲載」は**事実でも**書かない
5. **不安あおり**（Ⅵ.4(5)）— 症状を並べて「放置すると危険、当院へ」。受診勧奨の宛先は医療機関
6. **早急な受療・費用の強調**（Ⅵ.4(4)）— 「今すぐ」「先着」「初回0円」を大きく見せる
7. **自費施術**（Ⅵ.3）— 載せるなら **内容・費用・主なリスク** の3点をセットで書く
8. **健康保険の誤った説明** — 柔道整復の療養費は**骨折・脱臼・打撲・捻挫・挫傷**（急性・亜急性の外傷性のもの）が対象。
   「肩こり・慢性の腰痛も保険で」は書かない。骨折・脱臼は応急手当を除き**医師の同意が必要**

## advertising モードの判定基準

**1文ずつ、下の「書ける事項」のどれに当たるか対応づける。当たらない文は削除。**

書ける事項は、柔整師法24条1項と柔整広告告示、その具体的な範囲を示した指針Ⅲ章だけ。
**以下は2026-10-21に指針（令和7年2月18日）Ⅲ章の原文で確認した内容。** 法令審査役は `item` にこの番号を書く。

| 指針 | 書ける事項 | 書き方の例・範囲 | 書けない例 |
|---|---|---|---|
| Ⅲ.3(1) | 柔道整復師である旨、氏名・住所 | 「柔道整復師（国家資格保有）」 | 整体・カイロ等の民間資格、海外の類似資格 |
| Ⅲ.3(2) | 施術所の名称 | 「○○接骨院」「○○施術所（院）」 | 名称に**整体**・カイロ・リラクゼーション・クリニック・メディカル・治療院・リハビリ・スポーツ・○○専門・センター・サロン 等。可と不可の**併記も不可**（キ）。**看板と違っても、広告上は不可の語を外す** |
| Ⅲ.3(3) | 電話番号・所在の場所 | FAX、電話の受付時間、郵便番号、**最寄駅等からの道順・所要時間・案内図・地図**、**情報の伝達に関する事項（電子メールアドレス・ウェブサイトのURL・QRコード 等）** ← LINE の友だち追加URL・ボタンはここ | 「1374（痛みなし）」のような語呂合わせ |
| Ⅲ.3(4) | 施術日・施術時間 | 受付時間、施術曜日、**休日（休療日）**、時間による施術内容の別 | **「診」の字**（診療・診察・休診・初診・往診 等） |
| Ⅲ.4(1) | 開設届出をした旨 | 「○月○日 ○○県 開設届出済」 | 厚労省認定・知事認可 等 |
| Ⅲ.4(2) | 医療保険療養費の支給申請ができる旨 | 骨折・脱臼は**医師の同意が必要な旨の明示が条件**。「外傷性が明らかな骨折、脱臼、打撲、捻挫等が対象」の併記は可 | 各種保険取扱い・労災保険・**自賠責保険**・**交通事故取扱い** |
| Ⅲ.4(3) | 予約に基づく施術、休日・夜間の施術 | 「予約優先」、**FAX・電子メール等で予約を受け付けている旨** | — |
| Ⅲ.4(4) | 出張による施術 | 範囲・地域、時間、「訪問施術の実施」 | 訪問診療、往診 |
| Ⅲ.4(5) | 駐車設備 | 有無、場所、写真、料金、台数 | — |
| Ⅲ.2(1) | 表現手段 | 上の事項なら、写真・イラスト・映像でもよい | — |
| Ⅲ.5 | 規制対象外 | 背景の風景写真・イラスト、幾何学模様 | 芸能人が利用者である旨 |

advertising モードで**書けないもの**: 症状・適応の列挙、施術内容の説明、施術者の経歴、料金、FAQ、院のこだわり、共感の文章、
効果を示唆する写真・イラスト。上の表に当たらない文は、事実であっても削る。

## 機械判定（L1）と審査（L2）

| 層 | 誰が | 何を |
|---|---|---|
| L1 | `scripts/legal_check.py` | NG語の文字列一致、必須記載の有無、構造（自費とリスクのセット等） |
| L2 | `lp-legal-reviewer` | 言い換え・文脈・画像・モードごとの書ける範囲。**L1が通っても L2 で落とす** |

```bash
python3 "$PLUGIN_ROOT/scripts/legal_check.py" <copy.md または index.html> --mode website|advertising
```

L1 は文字列一致なので言い換えを取りこぼす。**L1の通過は合格の理由にならない。**

## 指摘の分類コード

法令の指摘（審査役の `findings[].item`、L1 のカテゴリ名、knowledge の `rejections.jsonl`）は、
**`scripts/legal_items.py` の `CANONICAL` にあるコードだけ**を使う。案件をまたいで集計するため。

- 書き方は `Ⅵ.4(1)` `Ⅲ.3(2)` のように「ローマ数字・点・算用数字・半角かっこ」。細かい条項（②イ など）は `ref`
- advertising モードで書ける事項に当たらないものは `柔整師法24条`。Ⅲ章のコードは、その項目の具体的な禁止に当たったときだけ
- brief にない事実は `事実未確認`
- 付け方の詳細は `agents/lp-legal-reviewer.md` の「item（分類コード）の付け方」。保存時にフックが `check_review.py` で検査する

コードを増やすときは `CANONICAL` に足し、表記ゆれは `ALIASES` に足す。既存の記録は `scripts/migrate_rejections.py` で付け直す。

## 必須記載（website モード）

- 問い合わせ先（電話番号または予約手段） — Ⅵ.3(1)
- 医療機関への受診勧奨の一文
- 自費施術を載せる場合: 内容・費用・主なリスク — Ⅵ.3(2)(3)
- 保険について書く場合: 対象となるケガの範囲

## NG語を追加するとき

`scripts/legal_check.py` の `NG` 辞書に、**指針のどの項目に対応するか**をキーにして足す。
院独自のNG語は `brief.md` の `extra_ng_words` に書けば `--brief` オプションで読み込まれる。
